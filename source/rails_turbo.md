JavaScript and Rails
================================

This guide covers the built-in JavaScript functionality of Rails 7 and 8;
it will enable you to create rich and dynamic web applications with
ease!

After reading this guide, you will know:

* where Javascript code goes in a Rail app
* how to javascript libraries through importmaps in your Rails app,
* how Rails avoids loading full HTML pages with Turbo,
* how to use stimulus controllers
